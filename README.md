# GrafLab labels

Векторные макеты этикеток БАД и скрипты допечатной подготовки: замена текстовых блоков, даты партий, штрихкоды, экспорт PDF/SVG и проверка геометрии.

В корне сохранены варианты берберина и магния B6 с PNG-превью. В `output/pdf/` — итоговые наборы, лактоферрин и вариант магния для Max Lab. Названия REVIEW обозначают варианты на согласование.

## Инструменты

```sh
pip install -r requirements.txt
python build_berberin_v3.py
python qa_berberin_v3.py
```

Скрипты используют пути относительно репозитория. Для некоторых операций потребуются исходные PDF в `input/`; имена указаны в соответствующих скриптах. Шрифты берутся из `C:/Windows/Fonts`: PT Sans Narrow, Futura, Montserrat и Bebas Neue. Установите используемые гарнитуры отдельно. Новые результаты могут перезаписывать сохранённые макеты; рабочие правки лучше выполнять в отдельной копии.

PDF и SVG представлены как работы по дизайну и подготовке к печати. Тексты и даты относятся к сохранённым версиям макетов.
